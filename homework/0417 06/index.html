1
回呼函式（Callback） callback 
// 建立一個能接受回呼函式的通用工具 
function mathTool(num1, num2, action) { 
  return action(num1, num2); 
} 
 
console.log(mathTool(10, 5, function (a, b) { 
  return a + b; 
}));  // 15 
 
console.log(mathTool(10, 5, function (a, b) { 
  return a - b; 
}));  // 5
重點 — 將「行為」當作參數傳入函式，action 就是一個 回呼函式（callback）。這樣 mathTool 只負責流程，實際運算由外部決定。
2
立即執行函式（IIFE） IIFE 
(function () { 
  let count = 100; 
  console.log("Count is: " + count); 
})();  // Count is: 100
重點 — IIFE（Immediately Invoked Function Expression）在定義的「當下」就執行，常用來建立獨立作用域，避免變數污染全域。
3
map() 與箭頭函式 array 
const prices = [100, 200, 300, 400]; 
const discountPrices = prices.map(price => price * 0.8); 
 
console.log(discountPrices); 
// [80, 160, 240, 320]
重點 — map() 遍歷陣列並「回傳一個新陣列」，不修改原陣列。箭頭函式 price => price * 0.8 寫法更簡潔。
4
陣列方法：pop() & unshift() array 
function cleanData(arr) { 
  arr.pop();           // 移除最後一個元素 
  arr.unshift("Start"); // 在最前面加入 "Start" 
} 
 
let myData = [1, 2, 3]; 
cleanData(myData); 
console.log(myData);  // ["Start", 1, 2]
重點 — 陣列是「參考型別」，在函式內部修改陣列會直接影響原陣列。pop() 移除尾部，unshift() 在頭部插入。
5
閉包：函式回傳函式 closure 
function multiplier(factor) { 
  return n => n * factor; 
} 
 
const double = multiplier(2); 
console.log(double(10));  // 20
重點 — multiplier 回傳的箭頭函式「記住」了 factor 參數，這就是閉包（Closure）。可以用來「預先設定」某些參數。
6
自製 filter() callback 
function myFilter(arr, callback) { 
  let result = []; 
  for (let item of arr) { 
    if (callback(item)) { 
      result.push(item); 
    } 
  } 
  return result; 
} 
 
const numbers = [1, 5, 8, 12]; 
const filteredNumbers = myFilter(numbers, item => item > 7); 
console.log(filteredNumbers);  // [8, 12]
重點 — 手刻一個 filter 幫助理解其原理：回呼函式回傳 true 的元素才會被收集到新陣列。
7
物件陣列過濾 array callback 
const users = [ 
  { name: "Alice", age: 25 }, 
  { name: "Bob",   age: 17 } 
]; 
 
const adults = users.filter((user) => { 
  return user.age >= 18; 
}); 
 
console.log(adults); 
// [{ name: "Alice", age: 25 }]
重點 — 搭配 filter + 箭頭函式，可以很優雅地從物件陣列中篩選出符合條件的資料。
8
傳參考 vs 傳值 概念 
let listA = [1, 2]; 
let listB = [3, 4]; 
 
function process(a, b) { 
  a.push(99);     // 修改 a 指向的陣列 
  b = [100];        // 重新指派 b，不影響原 listB 
} 
 
process(listA, listB); 
console.log(listA);  // [1, 2, 99] 
console.log(listB);  // [3, 4]
重點 — a.push(99) 修改的是同一個陣列本身，所以 listA 改變了；b = [100] 只是讓區域參數 b 指向新陣列，原 listB 不受影響。這是 JS 中「傳參考」與「傳值」最經典的範例。
9
setTimeout 與箭頭函式 async 
const words = ["Task", "Completed"]; 
 
setTimeout(() => { 
  console.log(words.join(" ")); 
}, 2000); 
// 2 秒後輸出 "Task Completed"
重點 — setTimeout 是非同步函式，在指定延遲後執行回呼。箭頭函式搭配 join() 可以把陣列合併成字串。
10
購物車折扣（回呼應用） callback 
function calculateTotal(cart, discountFunc) { 
  let total = 0; 
  for (let price of cart) { 
    total += price; 
  } 
  return discountFunc(total); 
} 
 
const result = calculateTotal([100, 200, 300], function (total) { 
  return total - 50; 
}); 
console.log(result);  // 550
重點 — 實用的回呼應用：calculateTotal 計算總額，再透過 discountFunc 回呼套用折扣邏輯，讓折扣規則可以靈活抽換。
