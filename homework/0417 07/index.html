1

物件屬性存取

Object Property Access

從物件中取得屬性值，有兩種寫法：點符號（obj.key）與中括號（obj["key"]）。

let post = { id: 1, title: "Hello World" };
console.log(post.title);      // "Hello World"
console.log(post["title"]);  // "Hello World"
2

物件解構賦值

Object Destructuring

從 req.body 中直接取出 title 與 content，不必一個個寫 req.body.title。

const req = { body: { title: "JS教學", content: "內容在此" } };
const { title, content } = req.body;
console.log(title);   // "JS教學"
3

陣列遍歷 & 字串拼接

forEach / Template Literals

用 forEach 跑過文章陣列，把每一筆資料拼成 HTML 字串，這是動態產生網頁列表的核心技巧。

const posts = [{ id: 1, t: "A" }, { id: 2, t: "B" }];
let html = "";
posts.forEach(post => {
  html += `<div>${post.t}</div>`;
});
console.log(html);  // "<div>A</div><div>B</div>"
4

動態參數 / 字典

URL Params

模擬 Express 的 req.params——先建立空物件，再用中括號動態新增屬性，對應 URL 中的 :id 參數。

let params = {};
params["id"] = 99;
console.log(params);     // { id: 99 }
console.log(params.id); // 99
5

錯誤優先回呼

Error-First Callback

非同步函數的第一個參數保留給錯誤（err），第二個參數才是真正的資料。呼叫端用 if (err) 判斷是否成功。

function fetchData(id, callback) {
  const fakeData = { id: id, status: "success" };
  callback(null, fakeData);
}

fetchData(101, (err, data) => {
  if (err) console.log("錯誤：" + err);
  else    console.log("成功：", data);
});
6

JSON 解析

Parsing JSON

JSON.parse() 把後端收到的 JSON 字串變成真正的 JavaScript 物件，才能存取裡面的屬性。

const jsonStr = '{"title": "Post 1", "tags": ["js", "node"]}';
let obj = JSON.parse(jsonStr);
console.log(obj);        // { title: "Post 1", tags: ["js","node"] }
console.log(obj.tags[1]); // "node"
7

模擬資料庫查詢

Simulating DB Query

模擬 db.get(sql, params, callback) 的流程——傳入 SQL 與參數，透過回呼拿到查詢結果（row）。

function fakeGet(sql, params, callback) {
  callback(null, { id: 1, title: "掌握 JS 函數" });
}

fakeGet("SELECT * FROM posts WHERE id = ?", [1], (err, row) => {
  if (err) console.error("查詢失敗");
  else    console.log("標題：", row.title);
});
8

樣板字串邏輯運算

Template Literals with Logic

在反引號 `...` 的 ${} 裡可以直接寫條件判斷，決定輸出的內容。

let user = "Guest";
let html = `<h1>Welcome, ${user ? user : "Stranger"}</h1>`;
console.log(html);  // "<h1>Welcome, Guest</h1>"
9

字串截短 / 切片

substring

用 substring(0, n) 擷取前 n 個字元，再加上 ... 做出「閱讀更多」的效果，常見於文章列表。

const contents = ["Very long content here", "Another long content"];
contents.forEach(c => {
  console.log(c.substring(0, 10) + "...");
});
// "Very long ..."
// "Another Ve..."
10

錯誤優先回呼模式

if (err) return

若發生錯誤，callback(err) 後加上 return 中斷後續執行，確保成功邏輯不會在錯誤時被誤觸。

function checkAdmin(role, callback) {
  if (role !== "admin") { callback("Access Denied"); return; }
  callback(null, "Welcome");
}

checkAdmin("user", (err, msg) => {
  if (err) { console.log("錯誤：", err); return; }
  console.log("成功：", msg);
});
