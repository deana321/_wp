Reflection

學習心得

我學到了什麼

透過網頁設計課，我學習到如何使用 HTML 建立網頁架構，使用 CSS 設計版面與視覺風格，並透過 JavaScript 增加互動效果。

遇到的困難

在製作作業的過程中，我遇到版面排列、圖片路徑、語法錯誤與互動功能設定等問題。

未來想改進

未來希望能讓網頁版面更加美觀，並提升響應式網頁設計與 JavaScript 功能應用能力。
