作業詳細

作業一：個人介紹網頁 — Wz Profile Page

  • 作業主題：個人介紹網頁（Wz Profile Page）
  • 作業目的：學習使用 HTML 與 CSS 製作個人介紹頁面，熟悉版面設計與視覺風格
  • 使用技術：HTMLCSS
  • 作業內容：個人介紹檔，包含自我介紹、興趣卡片、時間軸、聯絡資訊等區塊
  • 學習重點：使用 CSS Grid 進行雙欄版面排列（如 header 左右分欄）；使用 CSS 偽元素 ::before / ::after 裝飾卡片
  • 遇到問題：手機版版面跑版，文字與元素重疊；背景漸層與星星裝飾的定位對齊不易
  • 解決方式：使用 @media 查詢設定 RWD 斷點，將 grid 改為單欄；裝飾層用 position: fixed + inset:0 固定，不影響內容流
  • 作業連結：開啟作業一
  • 使用 AI：opencode + ChatGPT 協助完成（對話紀錄）

作業五：網易網誌部落格系統 — Express Blog

  • 作業主題：全端部落格系統
  • 作業目的：學習使用 Node.js + Express + SQLite 建立完整的 Web 應用
  • 使用技術：Node.jsExpressSQLiteEJSbcrypt
  • 作業內容：使用者註冊/登入、文章 CRUD、Markdown 編輯、分類系統、留言功能、文章歸檔

Reflection

學習心得

我學到了什麼

從 HTML/CSS 靜態頁面開始，逐步學習 JavaScript 程式設計、Node.js 後端開發，再到 Next.js 框架應用。這學期我學會了如何獨立開發一個完整的 Web 應用，從前端版面到後端資料庫，涵蓋全端開發流程。

遇到的困難

最大的挑戰是期中專案的 Next.js 版本差異（v16 的 breaking changes），以及部落格系統的 bcrypt 與 session 設定。JavaScript 的 closure 和傳值傳址概念也花了不少時間理解。

未來想改進

希望未來能學習 TypeScript 增加程式碼可靠性，並深入 React 生態系（Next.js、Tailwind CSS）。也想嘗試串接真實 API 與資料庫，讓專案更具實用性。
