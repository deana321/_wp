# 美編設計筆記

## 配色方案

本專案採用粉色馬卡龍色系作為主題：

| 顏色 | 色碼 | 用途 |
|------|------|------|
| 背景粉 | `#FFF7FB` | 頁面背景 |
| 主粉色 | `#F7A8C6` | 主要按鈕、標題、強調色 |
| 薄荷綠 | `#B8E6D6` | 次要按鈕、成功狀態 |
| 奶油黃 | `#FFE7A3` | 標籤、美食分類 |
| 淡紫色 | `#D9C7FF` | 分類標籤、表格標頭 |
| 天空藍 | `#BFDFFF` | 資訊卡片、標籤 |
| 文字色 | `#4B3F46` | 主要文字 |
| 邊框色 | `#F3D7E3` | 卡片邊框、分隔線 |

## 筆記感 UI 設計

### 左側選單（筆記本分頁）
- 使用卡片白底搭配柔和陰影
- 導航項目左側有 3px 邊框，hover 時變為粉色
- 頂部有 CampusHub Notes 品牌標題，下方為使用者切換區

### 卡片設計（便利貼感）
- 圓角 12px（`border-radius: 12px`）
- 邊框 `1.5px solid var(--border)`
- 陰影 `0 4px 12px var(--shadow)`，hover 時加深
- 卡片內容有 20px 內距

### 標籤設計
- 圓角藥丸形狀（`border-radius: 20px`）
- 六種顏色對應不同分類
- 字體 11px，粗體

### 筆記紙元素
- 部分卡片使用 notebook-bg 類別，添加橫線背景圖案
- 邊框使用虛線（dashed）增加手帳感
- 分隔線使用 2px dashed 樣式

## 各頁面設計

### 首頁 Dashboard
- 雙欄布局，左側統計 + 動態，右側課表 + 連結
- 統計圖標使用大型 emoji
- 快速連結使用按鈕樣式

### 社群頁
- 貼文以筆記卡片呈現
- 每則貼文顯示使用者頭貼（emoji）、名稱、時間
- 分類標籤彩色標示
- 底部為按讚、留言、AI 摘要操作列

### 商店頁
- 商品以 4 欄網格排列
- 每個商品卡顯示 emoji 大圖、名稱、價格（粉色強調）
- 購物車為側邊滑出面板
- AI 按鈕使用奶油黃色

### 信箱頁
- 信件列表仿 Gmail 風格
- 未讀信件有粉紅背景色
- 已讀/未讀狀態以圓點標示
- AI 回信顯示在卡片中

### 校務頁
- 分頁切換四種功能（課表、成績、公告、清單）
- 課表使用表格，課程以薄荷綠標示
- 成績依分數顏色標記（綠/黃/紅）

### 搜尋頁
- 搜尋欄搭配分類過濾按鈕
- 結果以索引卡風格呈現，包含圖標、類型標籤

### 專案頁
- 類 GitHub 風格
- 專案卡顯示名稱、擁有者、星號數
- README 以等寬字體呈現
- Issue 列表與新增表單

### 排行榜頁
- 前三名使用金銀銅徽章
- 排名條目有 hover 位移效果
- 分數以粉色強調顯示
