# CampusHub Notes 🌸

**粉色馬卡龍校園社群整合平台**

一個結合校園社群、商店、信箱、AI、搜尋、專案管理與排行榜的多功能網站。

## 功能列表

- 💬 **社群** — 發文、留言、按讚、分類、AI 摘要
- 🛍️ **商店** — 商品展示、購物車、模擬結帳、AI 商品介紹
- ✉️ **信箱** — 收件匣、撰寫信件、已讀/未讀、AI 回信草稿
- 📚 **校務** — 課表、成績查詢、課程公告、課程 checklist
- 🔍 **搜尋** — 全站搜尋（貼文、商品、信件、課程、專案）
- 📂 **專案** — 類 GitHub 專案列表、README、星號收藏、Issue
- 🏆 **排行榜** — 提交分數、排行榜、前三名徽章
- 🤖 **AI** — 摘要、商品描述、回信草稿（本地模擬）
- 🏠 **首頁 Dashboard** — 概覽統計、今日課表、快速連結

## 安裝方式

```bash
npm install
```

## 執行方式

```bash
npm run dev
```

開啟瀏覽器至 http://localhost:3000

```bash
npm run build
npm start
```

## 使用技術

- **Next.js 16** (App Router) — 前端 + API 路由
- **React 19** — UI 元件
- **JSON File Database** — 輕量資料儲存
- **CSS** — 自訂粉色馬卡龍主題樣式
- **AI Fallback** — 本地模擬 AI 回覆
